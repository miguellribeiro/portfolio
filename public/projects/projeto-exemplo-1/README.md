# Imagens de `projeto-exemplo-1`

Coloque aqui as imagens deste projeto. Convenção de nomes:

- `cover.webp` — capa exibida no card (proporção 16:10, ~1200×750).
- `gallery-1.webp`, `gallery-2.webp`, ... — imagens da galeria/lightbox, em ordem.

Formato recomendado: **WebP**, até ~200 KB por imagem.
Os arquivos `.svg` atuais são **placeholders**: ao trocar, atualize `cover` e `gallery`
em `src/data/projects.json` (ex.: `"cover": "cover.webp"`).
Textos alternativos (alt) ficam em `src/data/locales/*.json` → `projects.items.projeto-exemplo-1.alt`.
